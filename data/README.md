# Data

`chicago_crimes_2019_2025.csv` — a 1,000-row sample of reported crimes from the City of
Chicago open data portal (`data.cityofchicago.org`), covering 2019 to 2025.

Columns: `id`, `date`, `primary_type`, `location_description`, `arrest`, `domestic`,
`community_area`, `year`, `latitude`, `longitude`.

The sample keeps the repo lightweight for the demo app. The notebooks document the
full-data workflow against the city's API.
